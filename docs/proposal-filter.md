# 提案画面フィルタ機能

## 概要

提案画面のリスト表示にステータスフィルタを追加する。

## フィルタ定義

| フィルタ名 | 条件                                          | デフォルト |
|-----------|----------------------------------------------|-----------|
| 実装待ち   | `checked=true`, `done=""`, `rejected=""`      | ON        |
| 未選択     | `checked=false`, `done=""`, `rejected=""`     | ON        |
| 実装済み   | `done` が非空                                  | OFF       |
| 非表示     | `rejected` が非空                              | OFF       |

- 複数選択可（トグルボタン方式）
- 各ボタンに該当件数を表示
- フィルタ状態はクライアント側で保持（API変更不要）

## 実装方針

- `client/index.html` のみ変更（サーバー側変更なし）
- フィルタバーを提案生成ボタンの下・ヒントの下に配置
- フィルタ切替時はAPIを再呼び出しせずキャッシュデータから再描画
- 既存のセクション分け（不採用折りたたみ/実装済みヘッダ）をフラットリストに統合
