# ログ同期ボタン機能

## 背景

AIの応答ストリーミング中にWebSocket通信が途切れ、ログ表示が途中で止まることがある。
ユーザーが手動で最新状態を取得できるボタンを設置する。

## 実装方針

### サーバー側 (`server/main.py`)

- WebSocketで `{"type": "sync"}` メッセージを受信できるようにする
- タスク実行中ならキューの再ドレインを開始する（再接続時と同じ処理）
- タスクが実行中でなければ `{"type": "notice", "content": "最新の状態です"}` を返す

### クライアント側 (`client/index.html`)

- thinkingインジケーター内に「最新ログ取得」ボタンを追加
- ボタン押下時に `ws.send(JSON.stringify({type: "sync"}))` を送信
- サーバーから新しいチャンクが来れば通常通り表示再開
- `notice` メッセージが来ればトースト表示（既に実装済みのhandler）

### 動作フロー

```
[ストリーム停止] → ユーザーが「最新ログ取得」ボタン押下
  → ws.send({type: "sync"})
  → サーバー: タスク実行中？
    → YES: _drain_queue 再開 → 溜まったチャンクが流れてくる
    → NO:  notice「最新の状態です」返却 → トースト表示
```
